# ✅ Todo List

A simple Todo List application for creating, managing, and tracking tasks.

## ✨ Features

* ➕ Add tasks
* ✏️ Update tasks
* 🗑️ Delete tasks
* ✅ Track completed tasks
* 📋 Manage daily tasks
* 🖥️ Simple user interface

## 🛠️ Technologies

* Python

## 🚀 How to Run

1. Install Python.
2. Clone this repository.
3. Open the project directory.
4. Run the application.

```bash
python main.py
```
